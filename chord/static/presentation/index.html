The Chord Ring

O(log N) Routing.
Every Time.

[Placeholder] The Chord algorithm is the mathematical heart of this system. Every node gets a position on a logical ring via SHA-1 hashing — and every job gets routed to its owner in at most O(log N) hops, guaranteed.

Finger Table

  • Each node stores O(log N) shortcuts
  • Skip ahead by powers of 2
  • 5 nodes → ≤ 3 hops max

Self-Healing

  • Stabilization (every 2s)
  • Node joins in ~2s
  • Failure recovery in ~3s
AI Orchestration

Three Agents.
One Goal.

Static rules ignore load. Fixed replication wastes or loses data.
Real-time metrics need real-time judgment.

🎯
Placement Agent
"Which node should run this job?"
Inputs
queue_depth jobs_failed node liveness
Selects node with lowest queue depth, weighted by failure history. Claude API call with structured tool.
Fallback: argmin(queue_depth) heuristic
📋
Replication Agent
"How many copies? Where?"
Inputs
job type ring health requested_replicas
Compute-heavy jobs get ≥2 replicas. Caps at live node count. Degrades gracefully on ring shrink.
Fallback: type-based heuristic (compute → +1)
🔄
Recovery Agent
"Node died. Now what?"
Inputs
orphaned jobs survivor metrics queue depths
Redistributes orphaned jobs to survivors, avoiding already-loaded nodes. Triggered on predecessor loss.
Fallback: round-robin across survivors

Observability

If You Can't See It,
You Can't Trust It.

Every node exports Prometheus metrics every 5 seconds. These dashboards are not just for humans — our AI agents read the same data to make real-time decisions.

📈
Request Throughput per Node
Requests per second handled by each node. A balanced ring shows an even distribution across all nodes — spikes signal routing skew or overloaded successors.
Goal: balanced
🔀
Average Hop Count
Number of ring hops taken to resolve each lookup. For a 5-node ring, O(log₂ 5) ≈ 2.3 — our correctness proof. If hop count climbs above 3, the finger tables need repair.
Goal: ≤ 3 hops
📊
Queue Depth per Node
Number of pending jobs waiting on each node. The Placement Agent reads this every 5 seconds to select the least-loaded node. Imbalance here directly drives AI decision-making.
Drives AI Agent
💚
Ring Health — % Nodes Alive
Real-time liveness score for the ring. 100% means fully operational. Below 60%, the Recovery Agent is triggered to redistribute orphaned jobs. Below 40%, replication is suspended.
100% = healthy
